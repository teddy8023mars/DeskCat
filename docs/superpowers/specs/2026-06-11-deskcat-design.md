# DeskCat — 桌面 3D 伴侣小猫 设计文档

日期：2026-06-11
状态：已获用户批准

## 目标

一个 macOS 桌面伴侣：一只立体的、漫画风的 3D 小猫，常驻桌面，头部（视线）平滑跟随用户的鼠标指针。

## 技术选型

- **Swift Package 可执行程序**（无需 Xcode 工程，`swift build` / `swift run`）
- **AppKit**：透明、无边框、置顶的 NSWindow（约 250×250），无阴影，可加入所有 Spaces
- **SceneKit**：在透明背景的 SCNView 中渲染 3D 猫模型
- **GLTFKit2**（SwiftPM 依赖）：加载从免费模型库下载的 glTF/GLB 卡通猫模型
- 模型来源：CC0 / CC-BY 免费授权（Poly Pizza、Quaternius 等），授权信息记录在 README

## 核心交互

1. **头部跟随**：每帧轮询 `NSEvent.mouseLocation`（无需系统权限），将鼠标屏幕坐标换算为相对小猫的 3D 方向，对头部节点做平滑插值旋转（带惯性延迟）。
   - 模型头部为独立节点/骨骼 → 只转头；
   - 一体化网格 → 退化为整猫上半身转向（可接受的降级方案）。
2. **鼠标靠近反应**：鼠标距小猫窗口中心小于阈值时，转头幅度加大并触发好奇动画。
3. **空闲小动作**：随机间隔触发摇尾巴（若尾巴为独立节点）/ 歪头 / 卡通挤压弹跳（squash & stretch，对任何模型有效）。
4. **拖动摆放**：按住小猫拖到任意位置，窗口位置存入 UserDefaults，启动时恢复。
5. **菜单栏控制**：🐱 状态栏图标，菜单含「显示/隐藏小猫」「退出」。

## 组件划分

| 组件 | 职责 |
|---|---|
| `main.swift` | NSApplication 启动（accessory 模式，无 Dock 图标） |
| `AppDelegate` | 窗口创建、状态栏菜单、位置持久化 |
| `CatWindow` / `CatView` | 透明窗口 + SCNView 子类，处理拖动 |
| `CatScene` | 模型加载、节点发现（head/tail/ear）、相机与灯光 |
| `CatBrain` | 每帧更新：头部跟随、靠近检测、空闲动画调度 |

## 错误处理

- 模型加载失败 → 弹窗提示并退出（资源随包分发，正常不会发生）
- 找不到 head 节点 → 自动降级为整体转向，不报错

## 验收标准

- `swift run` 启动后桌面出现透明背景的 3D 小猫
- 移动鼠标，小猫头部平滑转向指针方向
- 可拖动、可经菜单栏隐藏/退出，重启位置保持
- 提供打包脚本生成双击即用的 `DeskCat.app`
